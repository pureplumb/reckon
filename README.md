# reckon

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run start
```

To run tests:

```bash
bun test
```

To type check:

```bash
bun check
```

Run `bun fmt` to format the code.

This project was created using `bun init` in bun v1.4.5. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
